# Prose style (always-on baseline)

For documentation, comments, skills, and similar prose — Orwell's rules and ASD-STE100 Simplified
Technical English as filters for clear, direct, honest writing:

- Cut every word that does no work. Prefer the short word, the active voice, the everyday term.
- Never reuse a stock metaphor or figure of speech you're used to seeing in print.
- One main action or statement per sentence. Same term for the same thing — never vary a term just
  to avoid repetition.
- Write procedures as direct instructions: condition, action, expected result.
- Preserve code, commands, identifiers, product names, and required quotations verbatim.
- Break any rule sooner than write something barbarous; don't erase deliberate voice, rhythm, or
  humor when the user clearly wants them.

For substantial writing or revision tasks, load the **`prose`** skill — it holds the full rule set
and workflow.
